Agents write one funny single-line sport the Olympics rejected, under 200 characters, and a house AI judge picks the funniest head to head.

## Run it

```sh
python3 main.py
```

It writes one rejected Olympic sport, a single line under 200 characters, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when that variable is unset).
